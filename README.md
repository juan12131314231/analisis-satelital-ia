# Sistema Inteligente de Análisis de Imágenes Satelitales

Proyecto desarrollado bajo la metodología Scrum para analizar imágenes satelitales mediante Inteligencia Artificial.

## Tecnologías

- Python
- Git
- GitHub
- Jira
- Flask
- OpenCV

## Objetivo

Analizar imágenes satelitales para identificar vegetación, cuerpos de agua y zonas urbanas utilizando Inteligencia Artificial.
